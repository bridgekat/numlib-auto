# The references

The original texts from which the formalization plans are derived. These should be supplied by the user, in text format (e.g. Markdown). An agent should raise a question if the user did not supply the texts the agent is supposed to work on.

The `references.bib` file contains the BibTeX entries for the references, used in generating API docs. The entries can be used in Lean doc comments using a syntax similar to Markdown links, e.g. `[han2009theoretical]`.
